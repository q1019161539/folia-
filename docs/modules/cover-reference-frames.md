# 免费本地封面参考帧

## 范围

`backend/cover_frames.py` 是独立、CPU-only 的选帧模块及命令行入口，只用 FFmpeg、FFprobe、现有 Pillow。没有网络调用、视觉模型、付费 API、本地标题合成或投稿动作。不修改歌曲身份、数据库、原录播、切片或成片，不重渲染视频。

V2的publish_v2.py准备阶段调用select_reference_frame，取得frame_path和时间点；与原渲染结果隔离，不挂入旧模板叠字prepare。没有合格帧返回manual_review，不得自动付费生图。投稿状态、白名单和上线水位详见automatic-publishing.md。

## 算法与持久化

- 在视频 10%–90% 时间区间均匀抽取 12 张 640 像素宽候选。
- 按主播配置人物区域 `[left, top, right, bottom]`，坐标为 0–1 的边界，不是宽高。只将该区域归一到固定尺寸计算灰度亮度、黑/白像素比例、Laplacian 方差清晰度、64 bit 差分哈希。
- 排除过暗、过亮、过于平滑的候选；按质量排序后去重，近似相同的区域保留得分最高者；平分时固定取更早时间点。
- 在选中时间点另抽原分辨率 PNG，不裁剪或美化交给生图的原图。
- `selection.json` 保存算法版本、来源路径/大小/mtime_ns、主播/区域、候选时间及评分/拒绝原因、选中时间点、PNG 尺寸与 SHA-256。缓存键包含上述输入和候选数；原图校验通过时复用，不再抽帧。参数或视频变化会产生新的缓存目录。
- 独占锁防止并发重复抽帧；进程崩溃遗留锁不自动抢占，确认旧进程已停止后人工移除该锁。未完成的 attempt 目录保留用于诊断，原子写入成功记录后才可缓存。选帧前后检查源大小/mtime，变化则拒绝持久化结果。

配置示例 `backend/cover_frame_regions.example.json` 的芒芒、小红泡区域基于 2026-10-07 实际画面，不代表其所有历史布局。其他主播没有配置时明确返回 `region_configured=false` 并采用全画面评分；上线前应逐主播核对区域，不能猜人物位置。

## 调用与验收

容器内示例：

```sh
python /app/cover_frames.py /output/主播/日期/分类/歌名/成片.mp4 --output-root /data/cache/cover-frames --streamer 主播 --regions /data/cover-frame-regions.json
```

不要让输出目录指向原录播目录。图片路径属于本地容器；后续生图接口使用图片内容，不要求复制 MP4。

2026-10-07：11 项单测通过。在 NAS 独立断网、1 CPU、512 MiB 容器里只读使用两首成片：芒芒《一笑倾城》9.17 秒完成、选 8.8081 秒；小红泡《喂猪》全画面初测 11.47 秒、选 56.770327 秒；根据实际画面配置区域后复测 10.59 秒、选 17.842103 秒。输出均 1920×1080 PNG；缓存复用及原视频大小/mtime 不变通过。验收资料保存在 NAS `/vol1/1000/docker/folia-cover-frame-test-20261007/results/`。

## 限制

独立镜像 `folia-cover-frame-check:20261007` 构建成功，无源码挂载时确认 `/app/cover_frames.py` 可导入；镜像内断网执行上述 11 项测试通过。生产容器未重启，模块尚未挂入自动流程。

这是画质启发式，不是人物理解：不能可靠判断闭眼、表情、扇子遮脸、弹幕是否遮挡或画面中是否有主播。清晰字幕或衣服纹理也可能拉高评分，区域配置能减轻但不能消除。差分哈希只用于近似去重，不证明人物身份一致。布局变化需重配区域；全候选无效只进入人工处理，不随便取一张兜底。后续需要更多主播实际样本验收，不能据两首宣称批量封面效果已全部合格。
